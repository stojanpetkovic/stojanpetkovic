## Ausgangslage

**Kako se pravi** („Wie man es macht“) ist eine Website mit Hausrezepten und Heimwerker-Anleitungen: Brot, Pita, Kajmak, Rakija, Seife und Holzkohle, Schritt für Schritt erklärt. Sie lief auf einem **PHP-Magazinskript mit Datenbank**: Bei jedem Besuch setzte der Server die Seite aus PHP und SQL zusammen, darüber lag ein schweres Bootstrap-Theme. Die Seiten waren langsam, die Adressen hingen vom Skript ab, und jedes Update des Skripts war ein Risiko.

Der Kunde wollte **dieselbe Website und dieselben Adressen, aber so schnell, wie eine Website nur sein kann**, weiterhin auf demselben gewöhnlichen cPanel-Hosting. Außerdem sollten AdSense, Analytics und beide Meta Pixel weiterlaufen und die Website das Gesicht eines echten Kochmagazins bekommen.
